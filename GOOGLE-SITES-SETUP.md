# CART3R Gaming Hub — Google Sites setup

This project is prepared to be embedded in a new Google Site. The Google Sites page itself must be created and published from the owner's Google account; there is no connected Google Sites publishing integration in this workspace.

## Create the new Google Site

1. Open https://sites.google.com/new while signed in to the Google account you want to own CART3R.
2. Choose **Blank**.
3. Set the site name to **CART3R Gaming Hub**.
4. Set the page title to **CART3R GAMING HUB**.
5. Add a short intro: **Original browser games, instant play, and a place to discover games.**
6. Add pages named **Home**, **CART3R City**, **Arcade**, and **Game Library**.

## Embed the playable CART3R website

For each page:
1. In Google Sites, select **Insert → Embed → By URL**.
2. Paste the URL below.
3. Choose **Insert**, then resize the embed to use the available page width and height.
4. Use **Preview** to test desktop and mobile layouts.

Suggested embeds:

- Home: https://cart3r-gaming-hub.onrender.com/
- CART3R City: https://cart3r-gaming-hub.onrender.com/#city
- Arcade: https://cart3r-gaming-hub.onrender.com/#arcade
- Game Library: https://cart3r-gaming-hub.onrender.com/#discover

If Google Sites does not accept a URL with a fragment (the part after #), embed the home URL and use the navigation inside CART3R instead.

## Publish

1. Click **Publish** in Google Sites.
2. Choose a web address, such as `cart3r-gaming-hub`, if it is available.
3. Set the published-site audience to the intended audience. For a public site, select the available public visibility option.
4. Publish, then open the published URL in a private/incognito window to verify access.

## Important access note

Google Sites does not bypass GoGuardian, school firewalls, or other network restrictions. A school administrator may need to approve the Google Site and the embedded CART3R host. An embed can also be blocked by the network even when the Google Sites page itself loads.

## Deployment note

The CART3R server has been configured to permit framing by Google Sites domains. That change and the new CART3R City page need to finish deploying on Render before the embed will show the latest version. Use the live site URL above for the embed source.
